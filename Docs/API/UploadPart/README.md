# UploadPart — инструкция для агента

Открой [локальный снимок статьи](UploadPart.md).

1. Уточни назначение операции, тип ресурса и применимые типы бакетов.
2. По разделам **Request Syntax**, **URI Request Parameters** и **Request Body** выпиши HTTP-метод, endpoint, параметры пути и строки запроса, заголовки и тело. Отметь обязательные поля, IAM-действия и ограничения.
3. По разделам **Response Syntax**, **Response Elements** и **Errors** опиши коды ответа, поля, особые случаи и условия безопасного повтора, если AWS их документирует.
4. Проверь допустимые номера и размеры частей, поведение при повторной отправке того же номера и параметры checksum.

Если нужен алгоритм совместимой реализации, отдели наблюдаемый контракт AWS от проектных решений. В качестве подтверждения укажи раздел локальной статьи.
